# Scoring Model

Positive weights: importance .18, urgency .13, pain .12, revenue .11, retention .10, activation .09, trust .07, uniqueness .06, strategic fit .08, evidence .06. Subtract difficulty .07 and operational cost .03. Inputs range 1–5; output is clamped to 0–5.

Thresholds: 3.5 Build Now, 2.8 Build Next, 2.1 Consider, 1.4 Later, otherwise Ignore. Security launch blockers override to Build Now. Costly low-evidence work becomes Validate First. Simplicity-damaging work becomes Do Not Build Yet.
