# Quality & Verification

Use these skills for negative claims, proof packages, rollback safety, and deciding where limited review or testing effort matters most.

| Plugin | Primary use |
| --- | --- |
| [absence-proof-auditor](./absence-proof-auditor) | Test claims about what is absent with bounded, multi-surface evidence. |
| [change-proof-bundle](./change-proof-bundle) | Package a completed change with independently checkable evidence. |
| [reversibility-map](./reversibility-map) | Expose hidden one-way effects and the last safe rollback point. |
| [verification-budget-router](./verification-budget-router) | Route testing and review effort toward consequential failures. |

Each directory is an installable Codex plugin. The category is the primary use case; some skills are intentionally useful across more than one category.
