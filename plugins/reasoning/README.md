# Reasoning & Context

Use these skills for understanding context, preserving intent, making decisions reproducible, improving handoffs, finding blind spots, and evaluating work from multiple angles.

| Plugin | Primary use |
| --- | --- |
| [context-compressor](./context-compressor) | Create compact project memory and task-specific repository briefings. |
| [decision-replay](./decision-replay) | Record why a technical or product decision was chosen and when it should be revisited. |
| [evidence-debt-ledger](./evidence-debt-ledger) | Prioritize assumptions and claims that need stronger or fresher evidence. |
| [handoff-entropy-check](./handoff-entropy-check) | Make a work handoff safe for a fresh agent or engineer to continue. |
| [intent-drift-guard](./intent-drift-guard) | Keep implementation changes inside the user’s authorized scope. |
| [rigor](./rigor) | Run a balanced, multi-pass evaluation and reach an evidence-backed conclusion. |
| [unknown-unknown-hunt](./unknown-unknown-hunt) | Probe for failure classes that ordinary happy-path reviews may miss. |

Each directory is an installable Codex plugin. The category is the primary use case; some skills are intentionally useful across more than one category.
